איך מזמינים באתר?

  1. בוחרים את הספר באתר.
  2. מעלים תמונה של הילד/ה (איזו תמונה מתאימה?).
  3. רושמים את שם הילד ומוסיפים הקדשה (אפשר להכין במחולל למעלה).
  4. בוחרים את סוג הכריכה ומוסיפים לסל.
  5. המחיר מתעדכן אוטומטית עם כל ספר שמוסיפים לסל.
  6. מזינים את קוד הקופון, משלמים ושולחים את ההזמנה.
